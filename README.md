# 무회의령 화물국

`GAME_DESIGN.md`를 바탕으로 만든 의존성 없는 모바일 세로형 우주 택배 적재 퍼즐입니다.

## 실행

프로젝트 루트의 `index.html`을 브라우저에서 직접 여십시오. 서버, 빌드, 패키지 설치가 필요 없습니다.

## 조작

1. 일반·특급·위험물 계약 중 하나를 선택합니다.
2. 해금된 목적 행성을 고르고 상차를 시작합니다.
3. 컨베이어 위 곡선 화물을 누르거나 터치한 채 상단 적재칸으로 드래그합니다.
4. 붉은 경계·겹침 표시가 사라진 위치에 놓습니다.
5. 필요할 때 컨베이어 `정지`, `가속`, `역회전`을 사용합니다.
6. 적재율, 안정도, 예상 수익, 엔진 진동을 확인하고 출항합니다.
7. 5초 운송 중 충격 경보에 맞춰 `자이로 보정`과 `긴급 클램프`를 사용합니다.

화물칸을 업그레이드하면 적재 공간이 세로로 확장됩니다. 적재칸 위의 `확장 화물칸 이동` 손잡이를 위아래로 드래그하거나 키보드 방향키로 보이지 않는 구역을 확인할 수 있습니다.

적재율은 곡선 화물의 원형 구성요소가 차지하는 추정 면적을 최종 사용 가능 짐칸 면적으로 나눠 계산합니다. 90% 이상이면 `PERFECT FIT` 보너스를 받습니다.

## 구현 기능

- 포인터 이벤트 기반 마우스·터치 화물 드래그
- 여러 원이 결합된 CSS 곡선형 화물과 경계·원형 충돌 검사
- 실시간 컨베이어 이동, 제한 횟수 정지·역회전, 과열 가속
- 적재 제한시간과 실시간 적재율·안정도·수익·진동 계산
- 일반·특급·위험물 3중 계약 선택
- 지구권·저중력 달·고중력 화성의 서로 다른 중력과 유료 해금
- 무거움·미끄러움·파손주의·폭발물 속성 및 사전 위험 표시
- 5초 배송 연출, 연료 소비, 잔여 연료 보너스, 액티브 능력
- 성공·파손 원인과 지급액을 보여주는 배송 정산
- 돈으로 엔진·연료 탱크·화물칸과 역할별 직원 업그레이드
- 업그레이드된 확장 화물칸의 드래그·키보드 시점 이동
- 화물·행성·직원·우주선 도감 및 진행도
- `localStorage` 자동 저장과 기록 초기화
- 44px 이상 터치 영역, 키보드 버튼 조작, ARIA 레이블, 모션 감소 설정
- 데스크톱 중앙 휴대폰 프레임 및 모바일 스크롤·오버스크롤 대응

## 파일

- `index.html`: 화면 구조와 접근성 마크업
- `styles.css`: 산업 우주항 테마, 곡선 화물, 우주선 및 반응형 화면
- `game.js`: 게임 상태, 드래그·충돌, 운송 판정, 성장·저장 로직

저장 데이터 키는 `nan26-freight-save-v1`입니다.
